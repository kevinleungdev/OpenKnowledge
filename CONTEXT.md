# Open Knowledge

A surface for authoring Prompts and executing them as Runs. This glossary grows as the domain is explored; it currently reflects the Playground feature.

## Language

**Prompt**:
The content a user authors, intended to be executed as a Run. Each Prompt has a name (e.g. "Untitled prompt").
_Avoid_: Chat, conversation, session, document

**Run**:
The act of executing a Prompt against a model. Not yet implemented - the Run affordance is disabled.
_Avoid_: Execution, submission, send

**Run Settings**:
The parameters that govern how a Run executes.
_Avoid_: Run config, options, parameters
